# Stargram

이야기 한 줄을 인스타그램 게시물로 완성하는 iOS/iPadOS 앱입니다.

## 현재 구현

- iPhone 및 iPad용 SwiftUI 앱 프로젝트
- 이야기 한 줄 입력
- MZ·X·386·꼰대 스타일과 분위기·이야기 비중·글자 수 선택
- Apple 기기 AI 또는 로컬 생성, ChatGPT·Gemini·Grok 앱 왕복 작성
- 사진·영상 최대 10개 선택, 카메라 촬영, 대표 미디어와 순서 편집
- 게시물 미리보기, 문구 자동 복사와 Instagram 공유 화면 연결
- 개인 작성 기준과 프리셋 저장
- iPhone 및 iPad 세로 화면 지원

외부 AI 앱은 사용자가 직접 공유하고 결과를 붙여넣는 방식으로 연결되며 별도 API 결제가 필요하지 않습니다.
